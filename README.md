## 📥 التحميل والتثبيت

يمكنك تحميل أحدث إصدار من [**صفحة الإصدارات (Releases)**](https://github.com/Nyxoura/SARAB-multimedia-downloader/releases/latest).

تتوفر ملفات التثبيت لنظام **Windows** بصيغتي:
- **`.msi`** — مناسب للتثبيت القياسي أو الإداري على Windows.
- **`.exe`** — أداة التثبيت المباشرة لنظام Windows.

### خطوات التثبيت على Windows
1. انتقل إلى [**صفحة الإصدارات**](https://github.com/Nyxoura/SARAB-multimedia-downloader/releases/latest) وحمّل ملف `.msi` أو `.exe` المناسب لك.
2. شغّل ملف التثبيت واتبع التعليمات حتى اكتمال الإعداد.

## 🛠️ التطوير والبناء من المصدر

### المتطلبات

- [Git](https://git-scm.com/download)
- [Node.js](https://nodejs.org/)

### الخطوات

**0. فك ضغط كل من src-tauri و scripts و src**

**1. استنساخ المستودع**

```shell
git clone https://github.com/Nyxoura/SARAB-multimedia-downloader
cd SARAB-multimedia-downloader
```

**2. تثبيت الحزم**

```shell
npm install
```

**3. تشغيل وضع التطوير أو البناء**

```shell
npm run dev
```

```shell
npm run build
```
